01 / DATA JOURNEY

Bagaimana data bergerak

Contoh alur untuk dataset yang disimpan di CoreAnalytics.

01SumberDatabase, tabel, view, atau SQL Query
02Backend + BEAMMemvalidasi dan mencatat permintaan
03Dataset workerMengambil job dan membaca sumber
04ParquetHasil tersimpan pada storage
05Reader & insightData dibaca untuk analisis
Catatan: worker tetap terhubung ke database sumber untuk membaca data. Komunikasi worker ke metadata melalui BEAM memerlukan gateway, kunci khusus dan uji integrasi DEV terlebih dahulu.

04 / LOCAL DEVELOPMENT

Perintah terminal

Jalankan dari root proyek. Satu blok per terminal; jangan jalankan proses yang sama dua kali.

Perintah 5–6 untuk jalur BEAM hanya digunakan setelah gateway, kunci worker, dan uji kesehatan BEAM berhasil.

01 · Frontend
cd ~/CoreAnalyticsV2/voice-dashboard
npm run dev
02 · Backend / SQL Query DEV
cd ~/CoreAnalyticsV2
export STUDIO_PARQUET_READER_TOKEN_FILE="$HOME/.coreanalytics-reader-token"
bash scripts/start_dataset_query_probe_dev.sh
03 · Dispatcher ETL
cd ~/CoreAnalyticsV2
bash start_dispatcher_local.sh
04 · Parquet Reader
cd ~/CoreAnalyticsV2
export STUDIO_BATCH_STORAGE_ROOT="$HOME/CoreAnalyticsData/parquet"
export STUDIO_PARQUET_READER_TOKEN_FILE="$HOME/.coreanalytics-reader-token"
./data-studio-worker/.venv/bin/python data-studio-worker/reader/server.py
05 · Dataset Worker / BEAM DEV
cd ~/CoreAnalyticsV2
export STUDIO_WORKER_CONFIG_FILE="$HOME/.config/coreanalyticsv2/worker-beam.env"
export STUDIO_SQL_SCRIPT_DATASET_DEV_ENABLED=true
# Untuk sumber jaringan private tepercaya di DEV:
export STUDIO_SQL_ALLOW_PRIVATE=true
bash scripts/stored_dataset_worker.sh serve
06 · Scheduler / BEAM DEV
cd ~/CoreAnalyticsV2
export STUDIO_WORKER_CONFIG_FILE="$HOME/.config/coreanalyticsv2/worker-beam.env"
export STUDIO_INGEST_BACKEND_PYTHON="$HOME/CoreAnalyticsV2/.venv/bin/python"
bash scripts/studio_scheduler.sh serve
Sebelum menyalakan worker: job yang sudah mengantre dan jadwal yang telah jatuh tempo dapat langsung diproses. Tinjau pekerjaannya terlebih dahulu. SQL Query DEV dijalankan dengan izin akun koneksi sumber. Jika koneksi menggunakan sertifikat self-signed, pengecualian sertifikat hanya boleh diaktifkan secara eksplisit untuk uji DEV yang disetujui; opsi tersebut berlaku pada seluruh sumber worker yang sama.
05 / DEPLOYMENT

Siap untuk berkembang

Proses ≠ image

Satu image Docker dapat dipakai oleh beberapa layanan dengan perintah berbeda. Jumlah image ditentukan oleh dependensi dan rancangan deployment, bukan jumlah terminal.

Storage dan akses

Worker dan Reader harus mengakses storage Parquet yang sesuai. Kunci, token, serta kredensial dikelola secara terpisah dari image dan source code.
